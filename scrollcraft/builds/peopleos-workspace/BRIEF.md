Self-authored under explicit creative delegation, reusing the established user context. This is a scoped refinement of an existing working app, not a new interview or marketing landing page.

## Feeling curve, before the score

1. Orientation: selected country and current records establish the scope.
2. Curiosity: each coloured record is individually inspectable.
3. Clarity, the peak: selecting an affected person reveals the exact field, current value and validation rule beside the matrix.
4. Control: the existing exception dialog and migration studio provide the next action; approval remains explicit.

Peak sentence: “I could trace the readiness count to a person's source field, and see it clear after approving the workflow.”

Tell-someone sentence: “It's the site where every readiness mark is a person you can inspect and a correction you can review.”

No authored silence or empty scroll. The peak is the largest part of the new panel. It remains in natural flow and does not demand extra scroll distance.

## Grammar and fingerprint

Live surface: actual labelled synthetic data, real record selection and existing workflow entry points. Filmic one-shot and continuous world would obstruct operations; editorial, poster and cutlist would prioritize a narrative over work; catalog would turn records into displays; split stage would imply a before/after that has not yet been approved.

Registry was empty on inspection. Planned fingerprint: live surface / persistent application sidebar / inspectable record matrix / scope → select → inspect → act / source-exception input and review dialog / readiness lens. Root coordinates the shared registry after visual verification.

This small app refinement does not add four scroll effects merely to meet the long-form marketing-page device count. User-authorized scope requires restrained motion and preserved app behavior. No animated numerical interpolation, scrolling mutations, photographic planes, scrims or fake telemetry.

## Motion / mobile contract

The panel gets one short, small entrance as native scrolling brings it into view. Content is never hidden by default. Reduced motion drops translation. No animation loop, pinned space, automatic record selection or API request on scroll. Mobile replaces the dense button matrix with a labelled native employee selector and the same detail, so controls remain readable and comfortable to use.
